# Project Brief

- **Product vision:** Create a trusted digital bridge between food availability and genuine local food needs, enabling informed, targeted, meaningful food support.
- **Target audience:** Donors, individuals, organizations, CSR teams, NGOs, Ashram Shalas, schools, charitable institutions, community organizations, and administrators in Maharashtra.

## Conventions
- **Naming:** kebab-case files, PascalCase components/classes, camelCase functions/variables, UPPER_SNAKE_CASE constants and environment variables.
- **File structure:** Use a layered full-stack layout with a React client and Express server. Keep routes/controllers, services, repositories, validation, and feature UI modules separate. Colocate focused tests with the code they cover.

## Key Principles
- Ship the simplest solution that supports the WHERE -> WHY -> HOW journey.
- Keep official nutrition information and current local requirements as separate information layers.
- Show source, reporting period, and last synchronization information for official indicators.
- Use evidence-based, general, support-oriented food guidance; never diagnose or prescribe.
- Preserve privacy, auditability, support history, and dual confirmation.
- Use free/free-tier services where practical and keep the platform working without optional AI.
- Make the experience mobile-friendly, accessible, human-centered, and distinct from copied branding or generic AI-generated design.
